📘 USER GUIDE: TRAINING PLATFORM

Fast, simple and confusion-free

🎯 Goal: Learn where to find all tags, how to navigate the 3D space, how language works and how/when to take the final exam.

Rule #1: Review all tags — the exam questions come from them.

1. Side Menu & Tags (ESSENTIAL)

✅ What are tags?

Tags are the key “learning points” (information, instructions, mini quizzes). The final exam is based on their content.

⭐ What should I do?

  • Don’t skip tags — each one is exam content.
  • Follow the order to avoid missing any.
  • Do not forget to accept in each section that you have “completed” it in the corresponding checkbox that appears at the bottom part of the screen.

🟣 Tip: If you get lost, return to the menu and continue with the next tag.

2. 3D Space Navigation

Navigation is quick and intuitive. The most common actions:

  • Left click + drag → rotate view
  • Mouse wheel → zoom in / out
  • Click a spot / arrow keys → move around

If something doesn’t respond: zoom out a bit and click the spot again.

3. Languages (no confusion)

🌐 Inside a tag (top-right)

From there you switch the language of the tag’s text. This affects only the tag you are viewing.

🧩 Menu language / Final exam language

The side-menu language (language icon) also sets the language shown in the final exam.

🟣 Before starting the exam: make sure the menu is set to your preferred language.

4. Final Exam

🎓 How do I access it?

From the side menu, go to “START THE EXAMS” and click the tag that starts it.

✅ Pass requirement

To complete successfully, you need 70% (or the percentage defined by your organisation).

Questions are based 100% on the content of the tags.

5. Quick Tips & Troubleshooting

💡 Quick tips

  • Review all tags before taking the exam.
  • If something isn’t clear, switch language inside the tag (top-right).
  • Before the exam, check the language using the side-menu icon.

🛠️ If something doesn’t load

  • Do a page refresh.
  • Wait a few seconds for 3D elements to load.
  • If it persists, restart the browser or try a different one.
